# SkateProgress für Android

SkateProgress ist eine offline nutzbare App, mit der du Skateboard-Tricks und Sessions festhältst.

- Trickliste mit Kategorien, eigenen Tricks, Favoriten, Übungsmarkierung und YouTube-Links
- Sessions mit schnellen Zählern für gelandete Tricks
- Statistiken und Session-Verlauf
- S.K.A.T.E.-Zähler für mehrere Spieler
- Wiki mit Suche, Kategorien und eigenen Begriffen
- Profil mit Standfuß, Push-Fuß und Setup (Deck, Achsen, Kugellager, Rollen)

## APK herunterladen

[Zur neuesten veröffentlichten Version](https://github.com/Chaozz2go/SkateProgress-Releases/releases/latest)

**Solange dort noch kein Release angezeigt wird, ist noch keine öffentliche Update-APK veröffentlicht.**

Die App benötigt Android 8 oder neuer. Lade die APK auf dein Android-Gerät und öffne sie. Falls Android nachfragt, erlaube die Installation aus dieser Quelle.

Beim ersten Wechsel von einer Debug-APK auf die dauerhaft signierte Release-APK kann Android ein direktes Update wegen der anderen Signatur ablehnen. In diesem Fall muss die Debug-Version zuerst deinstalliert werden. Dabei gehen ihre lokal gespeicherten Daten verloren. Danach können neuere Versionen mit demselben Signierschlüssel und höherem `versionCode` als Update installiert werden.

Der Quellcode liegt in einem privaten Repository. Dieses öffentliche Repository enthält nur Hinweise und die APK-Dateien unter „Releases“. Die App speichert deine Daten lokal auf dem Gerät und benötigt kein Konto.
