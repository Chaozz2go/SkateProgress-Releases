# SkateProgress für Android

SkateProgress hilft dir, Skateboard-Tricks und Sessions festzuhalten.

- Trickliste mit Kategorien, eigenen Tricks, Favoriten, Übungsmarkierung und YouTube-Links
- Sessions mit schnellen Zählern für gelandete Tricks
- Statistiken und Session-Verlauf
- S.K.A.T.E.-Zähler für mehrere Spieler
- Wiki mit eigenen Begriffen
- Profil mit Stance und Board-Zähler

## APK herunterladen

[Zur neuesten Version](https://github.com/Chaozz2go/SkateProgress-Releases/releases/latest)

Die App benötigt Android 8 oder neuer. Lade die APK auf dein Android-Gerät und öffne sie. Falls Android nachfragt, erlaube die Installation aus dieser Quelle.

**Beim ersten Wechsel auf die signierte Release-Version** muss die bisherige Testversion eventuell deinstalliert werden. Dabei gehen die lokal gespeicherten Daten verloren. Danach sollten zukünftige Versionen mit derselben Signatur als Update installierbar sein, sofern die Versionsnummer steigt.

Der Quellcode liegt in einem privaten Repository. In diesem öffentlichen Repository werden nur die installierbaren APKs und Hinweise veröffentlicht.
